# TODOList en TypeScript


## Especificaciones

Que sea un TodoList para gestionar las tareas en TypeScript
Se debe tener en cuenta:

- Prohibido usar push, slice, sort
- Las tareas tienen prioridades: low, medium, high
- De una tarea necesitamos id, title, priority, un check, para saber si esta completada o no: done


### Métodos a especificar
- creareTask
- toggleDone
- rename
- removeOne
- editTask
- pendingByPriority

Crear un main.ts en la carpeta todoList que permita ejemplificar una app de tareas.
